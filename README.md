# the-rest

A pointer/hub page for the random mini-tools scattered across the workspace's
repos — mostly `claude-workspace-pages` — so they can be found by tapping a
link instead of remembering a URL or digging through code.

**Live page:** `index.html`, served at this repo's GitHub Pages URL
(`https://technicallytechnicaldesign.github.io/the-rest/`, once Pages is
enabled — see below).

## How it stays current

`index.html` is **hand-maintained**, not generated. When a new mini-thing
shows up worth finding again, add a card for it in the relevant section (or a
new section) and commit.

## One-time setup: enable GitHub Pages

This repo doesn't have a Pages-enabling API call available from this session,
so it needs one manual step:

1. Go to **Settings → Pages** in this repo.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)`.
4. Save. The page will be live at the URL above within a minute or two.
